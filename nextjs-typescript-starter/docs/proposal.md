# 英语单词学习 H5 需求文档

## 1. 项目概述

面向小学生的 H5 英语单词学习应用：支持邮箱登录/注册，选择单词书进行单词学习，并记录学习进度。

**技术栈**：Next.js 14 (App Router) + React 18 + Tailwind CSS + NextAuth v5 (Credentials) + PostgreSQL (Supabase) + Drizzle ORM

## 2. 数据源

单词数据为 JSON 文件，每本单词书一个文件，位于 `danci-admin/temp/`：

| 文件名 | 书名 | 说明 |
|--------|------|------|
| `PEPXiaoXue3_1.json` | PEP 小学三年级上册 | PEP 人教版 |
| `PEPXiaoXue6_2.json` | PEP 小学六年级下册 | PEP 人教版 |

数据由管理员通过 danci-admin 或其他方式导入数据库 `books` / `words` 表（不在本应用开发任务内）。

## 3. 功能需求

### 3.1 底部 Tab 导航

底部固定两个 Tab：**首页**（`/`）与**我的**（`/mine`）。Tab 栏始终可见，内容随 Tab 切换。

### 3.2 首页（`/`）

按登录状态区分展示：

- **已登录**：
  1. **最近学习**（有学习记录才展示）—— 卡片显示书名 + 进度（如"已学 15/120 词"），点击从上次位置继续学习
  2. **单词书列表** —— 展示所有单词书卡片（封面 + 书名 + 词数），点击进入该书学习
- **未登录**：只展示单词书列表；点击任意单词书 → 自动切换到【我的】Tab → 弹出登录/注册 Popup → 登录/注册成功后进入学习页

### 3.3 登录/注册 Popup

登录与注册共用一个弹窗，可切换模式。元素：标题（登录/注册）、邮箱输入框、密码输入框、提交按钮、切换链接（"去注册"/"去登录"）。

- **登录**：NextAuth Credentials 校验邮箱密码；失败显示错误提示
- **注册**：先查重，不存在则 bcrypt 加密创建；成功后自动登录

### 3.4 我的（`/mine`）

- 显示当前用户邮箱
- 学习进度概览：每本单词书的进度条（如 "15/120 词"）
- 退出登录按钮：`signOut` 后返回首页

### 3.5 单词学习页（`/study/[bookId]`）

- **入口逻辑**：最近学习进入 → 从上次学习的下一个单词开始；单词书列表进入 → 从头开始（或继续上次进度）
- **卡片模式（精简视图）**：单词拼写 + 音标 + 中文释义 + 一条示例句（详情见 design.md 字段映射）
- **交互**：上一个/下一个按钮切换；点击卡片进入单词详情页；切换时记录学习进度

### 3.6 单词详情页（`/study/[bookId]/[wordId]`）

完整渲染 `content` 字段：音标（美/英）、发音、释义（中/英）、例句列表、短语列表、同根词（按词性分组）。底部有「返回学习」按钮。

## 4. 路由结构

```
/                          → 首页（Tab: 首页）
/mine                      → 我的（Tab: 我的）
/study/[bookId]            → 单词学习卡片页
/study/[bookId]/[wordId]   → 单词详情页
```

## 6. 数据模型（新增表）

**User**（用户表，已有）：

```sql
CREATE TABLE "User" (
  id       SERIAL PRIMARY KEY,
  email    VARCHAR(64),
  password VARCHAR(64)
);
```

**study_progress**（学习进度表，新增）：

```sql
CREATE TABLE "study_progress" (
  id                 bigint PRIMARY KEY GENERATED BY DEFAULT AS IDENTITY,
  user_id            integer NOT NULL REFERENCES "User"(id) ON DELETE CASCADE,
  book_id            varchar(100) NOT NULL REFERENCES "books"(book_id) ON DELETE CASCADE,
  current_word_index integer NOT NULL DEFAULT 0,
  created_at         timestamptz NOT NULL DEFAULT now(),
  updated_at         timestamptz NOT NULL DEFAULT now(),
  CONSTRAINT study_progress_user_book_unique UNIQUE(user_id, book_id)
);
```

`current_word_index` 表示已学完前 N 个单词（从 0 开始），学习时从该索引继续。

## 7. 字段渲染选择

- **卡片模式**：仅取 `content.word` 下的 5 个字段（拼写、美式音标、中文释义、首条例句英/中）做精简展示
- **详情页**：完整渲染 `content.word.content` 下全部字段（音标/发音/释义/例句/短语/同根词）

完整字段路径映射见 design.md。
