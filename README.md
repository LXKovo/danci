# danci
nest.js单词后台管理系统和h5应用开发

## 应用形式
- 后端管理系统
- h5应用
- 多端开发
  
## 技术亮点
- 数据清洗
github 高星的 单词资料库
数据清洗 (选择、格式化、审核)
- supabase 云端psql数据库
  关系型数据库
- 支持向量数据库
- 云端 BASS数据库
  Backend as a service
- ORM 
  不用写sql，不要做数据库的底层处理
  对象关系映射
  todo.save()保存
  对象和数据库一行记录对应起来

## 后台管理系统
### 单词书管理
维护单词书，包括单词书的创建、删除、更新、查询等操作。


### 管理员管理
- 注册一个超级管理员
- 添加管理员

/ ->注册超级管理员页面->登录
