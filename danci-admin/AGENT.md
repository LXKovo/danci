# 数据库表结构

本项目使用 PostgreSQL + Drizzle ORM，Schema 定义在 `lib/db/schema.ts`，迁移文件在 `drizzle/` 目录。

---

## 1. admin-users（管理员表）

```sql
CREATE TABLE "admin-users" (
  "id"          uuid PRIMARY KEY DEFAULT gen_random_uuid() NOT NULL,
  "name"        varchar(100) NOT NULL,
  "email"       varchar(255) NOT NULL,
  "password_hash" text NOT NULL,
  "role"        varchar(20) NOT NULL,          -- 'system-admin' | 'admin'
  "created_at"  timestamp with time zone DEFAULT now() NOT NULL,
  "updated_at"  timestamp with time zone DEFAULT now() NOT NULL,
  CONSTRAINT "admin-users_email_unique" UNIQUE("email")
);
```

## 2. admin-session（会话表）

```sql
CREATE TABLE "admin-session" (
  "token_hash"  varchar(64) PRIMARY KEY NOT NULL,
  "admin_id"    uuid NOT NULL
                  REFERENCES "public"."admin-users"("id") ON DELETE CASCADE,
  "expires_at"  timestamp with time zone NOT NULL,
  "created_at"  timestamp with time zone DEFAULT now() NOT NULL
);

CREATE INDEX "admin_session_admin_id_idx" ON "admin-session" USING btree ("admin_id");
```

## 3. books（单词书表）

```sql
CREATE TABLE "books" (
  "id"          bigint PRIMARY KEY
                  GENERATED BY DEFAULT AS IDENTITY,
  "title"       varchar(255) NOT NULL,
  "word_count"  integer DEFAULT 0 NOT NULL,
  "cover_url"   text,
  "book_id"     varchar(100) NOT NULL,
  "tags"        text,                          -- 逗号分隔的标签
  "status"      varchar(20) DEFAULT 'active' NOT NULL,
  "stage"       varchar(20) DEFAULT '小学' NOT NULL,
  "created_at"  timestamp with time zone DEFAULT now() NOT NULL,
  "updated_at"  timestamp with time zone DEFAULT now() NOT NULL,
  CONSTRAINT "books_book_id_unique" UNIQUE("book_id")
);
```

## 4. words（单词表）

```sql
CREATE TABLE "words" (
  "id"          bigint PRIMARY KEY
                  GENERATED BY DEFAULT AS IDENTITY,
  "wordRank"    integer,
  "headWord"    varchar(255),
  "content"     json,
  "bookId"      varchar(100) NOT NULL
                  REFERENCES "public"."books"("book_id") ON DELETE CASCADE,
  "created_at"  timestamp with time zone DEFAULT now() NOT NULL,
  "updated_at"  timestamp with time zone DEFAULT now() NOT NULL
);

CREATE INDEX "words_book_id_idx" ON "words" USING btree ("bookId");
```

---

## 表关系

```
admin-users ──< admin-session   (admin_id → id, CASCADE)
books ────────< words            (book_id → book_id, CASCADE)
```

- 删除管理员 → 级联删除其所有会话
- 删除单词书 → 级联删除该书下所有单词
